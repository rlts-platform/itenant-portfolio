**Manage your rental properties, tenants, leases, maintenance, and payments in one place.**

- [Product Website](https://i-tenant.com)
- [Try the Demo](https://i-tenant.com/demo)

## What is iTenant?

iTenant is a property management app built to make the day-to-day work of managing rentals easier to keep track of. Instead of jumping between different tools and piles of paperwork, property owners and managers can use one place to manage properties, tenants, leases, maintenance, payments, and documents.

## What can you do with it?

- **Manage properties:** Keep property and unit details organized and track occupancy information.
- **Manage tenants and leases:** Keep tenant records, applications, lease details, renewals, and move-outs together.
- **Handle maintenance:** Track work orders, urgency, scheduling, and vendor assignments.
- **Keep up with payments and finances:** Organize payment records, income and expenses, and financial reports.
- **Store documents:** Manage property documents, lease templates, and document or signature workflows.
- **Stay on top of tasks:** Use reminders and workflow tools for things like rent due dates, lease expirations, and move-in checklists.
- **Get help from AI tools:** Use the available assistant and property-insight features.

What’s available can depend on the setup of the app and its connected services.

## How it works

iTenant runs as a web app. Its interface is built with React, and it uses Supabase for backend services and authentication. Vercel is used to host the web application.

The app brings its different property-management tools together in one interface. Some features also rely on backend settings or integrations, so not every workflow is necessarily enabled in every environment.

## Built with

- **React and Vite** for the web app
- **Supabase** for backend services and authentication
- **Vercel** for hosting
- **Tailwind CSS and Radix UI** for the interface
- **React Hook Form and Zod** for forms and validation
- **Recharts** for charts and reporting
- **Stripe libraries** for payment-related functionality

## Project status

iTenant includes a range of property-management screens and workflows. How well each feature works depends on the connected backend services and configuration, so the app should be tested in its intended environment before relying on every workflow.
